# ggboundary: Trajectories Against Moving Boundaries (Safe Operating Space over Time)

A small grammar for boundary visualisations built on 'ggplot2'. Its core
is a value trajectory read against a boundary that may itself be fixed
or move over time, with overshoot and slack shaded on ordinary Cartesian
coordinates. Most "safe operating space" frameworks draw the boundary as
a fixed line; a complex-adaptive-systems view treats the safe threshold
as endogenous, so the boundary is a data series in its own right. The
package also ships the static Doughnut Economics chart (a polar snapshot
of the same primitives) and an expressive conch spiral for communication
and physical data objects, both documented as companions to the
Cartesian view rather than substitutes for it. Primitives: boundary
(scalar or series), trajectory, safe band, overshoot, slack, zone of
uncertainty. Keywords: doughnut economics, planetary boundaries,
resilience, safe operating space, adaptive capacity.
