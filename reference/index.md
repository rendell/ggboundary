# Package index

## Core

Read a trajectory against a fixed or moving boundary.

- [`geom_boundary()`](https://rendell.github.io/ggboundary/reference/geom_boundary.md)
  : Draw a trajectory against a (possibly moving) boundary
- [`boundary_plot()`](https://rendell.github.io/ggboundary/reference/boundary_plot.md)
  : Trajectory-against-boundary plot (themed one-call wrapper)

## Snapshot

The Doughnut, many dimensions at a single instant.

- [`doughnut()`](https://rendell.github.io/ggboundary/reference/doughnut.md)
  : Doughnut Economics chart (the safe and just space at one instant)

## Planetary boundaries

Feed the ecological ceiling from boundary status data.

- [`planetary_boundaries()`](https://rendell.github.io/ggboundary/reference/planetary_boundaries.md)
  : Planetary-boundary status as an ecological ceiling
